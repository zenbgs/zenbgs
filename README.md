## What I actually work on

Most of my work is unglamorous and specific: service portals, academic systems, and operational automation for institutions that still run much of their process on paper.

That brings constraints other projects rarely have. The staff who will maintain the system come from mixed technical backgrounds. Users arrive on inexpensive Android phones over patchy connections. Procurement moves slowly, so the stack has to stay boring and stay supported for years. Accessibility stops being optional when the audience includes parents of every age.

I like this work because the result is measurable. A letter request that used to take three days now takes an hour.
